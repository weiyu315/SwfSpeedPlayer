# SWF Player 使用說明

Windows x64 版本：解壓縮下載包，執行 `SWF-Player.exe`。

## 操作

1. 按「開啟 SWF...」或 Ctrl+O 選取 SWF，也可拖曳檔案到播放器。
2. 上方「倍速」選單提供 0.25×–4×，可於播放中切換。開啟另一個檔案時回到 1×。
3. 影片下方左側為播放／暫停按鈕：三角形代表可播放，雙直線代表可暫停。快捷鍵為 Ctrl+P。
4. 拖曳或點擊下方進度條跳轉。拖曳時暫停，放開後定位畫面與串流音訊；原本暫停的影片仍保持暫停。
5. 播放／暫停右側的「截圖」會擷取當前影片畫面，接著選擇 PNG 儲存位置。圖片不含視窗與控制列；取消儲存不會產生檔案。
6. F11 切換全螢幕；全螢幕時控制列隱藏，可按 F11 返回。

## 限制

- 倍速採用音訊重取樣，音高會改變。
- 跳轉以主時間軸的影格為單位，MP3 音訊定位可能有小幅誤差。
- 互動遊戲、外部串流、獨立音效與多條時間軸不保證能像線性影片一樣任意定位。
- 本下載包不含 `6022.swf` 或其他影片素材，請自行準備檔案。
