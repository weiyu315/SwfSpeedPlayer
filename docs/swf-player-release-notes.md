# SWF Player v0.1.0

基於 Ruffle 0.6.0 的 Windows x64 SWF 播放器衍生版本。

## 功能

- 選取本機 SWF 檔案。
- 0.25×–4× 影音同步倍速，可在播放中切換。
- 影片下方的進度條與加大的播放／暫停符號按鈕。
- 主時間軸跳轉，保留倍速與暫停狀態。
- 截取目前影片畫面，另存為 PNG，不含視窗與控制列。

## 使用方式

下載 `SWF-Player-v0.1.0-windows-x64.zip`，解壓縮後執行 `SWF-Player.exe`。測試影片不隨附，請自行選取 SWF。

## 已知限制與驗證狀態

- 倍速會改變音高，尚無變速不變調。
- 進度條針對 SWF 主時間軸；互動遊戲、獨立音效和外部串流可能無法像線性影片一樣跳轉。
- 私有測試素材 `6022.swf` 的倍速與跳轉已驗證；四個 MP3 測試點定位差約 49–67 毫秒。此素材不包含於發布內容。
- SWF 相容性受 Ruffle 支援程度影響。
